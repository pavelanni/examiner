# Экспорт ведомости результатов

В Teacher Review доступны кнопки выгрузки CSV и XLSX. Тема выбирается из выпадающего списка опубликованных тем и тем сданных
экзаменов. Пункт «Все темы» снимает ограничение по теме. Форма подхватывает
параметры URL `topic`, `status`, `from`, `to`, `date` и `timezone`.

Даты фильтра относятся к началу экзамена (`started_at`), как в #52.
Дата прохождения в файле берётся из `submitted_at`. Конечная дата фильтра
включительна. Часовой пояс по умолчанию — `Europe/Moscow`.
Экспорт охватывает все подходящие строки независимо от пагинации списка.

Пример для русского инстанса:

```text
/ru/review/export?format=xlsx&topic=Механика&status=reviewed&from=2026-11-01&to=2026-11-30
```

Преподаватель и администратор могут экспортировать все подходящие сессии.
Это соответствует текущим правам Teacher Review. Ограничение преподавателя
собственными темами остаётся продуктовым решением из #53.

## Данные

В ведомость входят сессии с непустым `submitted_at` и статусом `submitted`,
`grading`, `graded` или `reviewed`. Попытка, возвращённая в `in_progress`
после сбоя оценки, исключается даже при сохранённой дате сдачи.
Оценка утверждена только при `status = reviewed` и непустом `final_grade`.
До утверждения выводится «Не утверждена», преподаватель и дата утверждения
пустые. Нулевая утверждённая оценка сохраняется как 0.

Название экзамена берётся из сохранённой темы сессии. Для старых сессий
с неизвестной темой или сессий с пустой темой используется название blueprint.
ФИО берётся из `display_name`, группа — из `group_name`. Для существующих
пользователей группа по умолчанию пустая. Её можно задать при создании
пользователя в админке или в необязательной колонке `group` roster CSV,
используемого `examiner prep`.

CSV использует UTF-8 с BOM, `;`, восемь полей в каждой строке и стандартное
CSV-экранирование. Текст, начинающийся с `=`, `+`, `-` или `@`
(включая ведущие пробелы), предваряется апострофом для защиты от формул.

XLSX заполняется из `internal/statement/template.xlsx`, полученного из
вложения к #53. Порядок ФИО и группы приведён к текстовым требованиям issue.
Оценки — числа 0–100, даты — ячейки с форматом `dd.mm.yyyy`.
Все пользовательские строки записываются как текст.

Выдача файла журналируется с пользователем и временем. Ответ помечен
`Cache-Control: no-store`. Доступ разрешён преподавателям и администраторам.

## Проверка

```bash
go test ./internal/store -run 'Statement|Group' -count=1
go test ./internal/statement -count=1
go test ./internal/handler -run 'Statement|Group' -count=1
go test ./internal/userutil -count=1
```

Создайте студента с группой, сдайте экзамен и выгрузите ведомость до проверки.
Ожидается «Не утверждена». Затем подтвердите результат с оценкой 0 и
повторите экспорт. Ожидаются числовой 0, ФИО преподавателя и дата утверждения.
Откройте CSV и XLSX в Excel и проверьте кириллицу, даты и заголовок предмета
из `exam_metadata.subject`.
